## How to use this file

When something doesn't work as expected — an agent produces a bad draft, a template is missing a section, the style guide was ambiguous — record it here first. Then decide:

- **Initiative-specific finding** → stays in this file
- **Reusable improvement** → update the relevant shared file (`agents/`, `templates/`, `style_guide.md`, or create an ADR)
